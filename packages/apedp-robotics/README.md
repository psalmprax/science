# APEDP-Robotics

Autonomous Robotics Trajectory Transport, SE(2)/SE(3) Kinematics, High-Order Symplectic Steppers, and Lyapunov Goal Navigation.

## Installation

```bash
pip install -e packages/apedp-robotics
```

## Features

- **Exact Kinematics**: Exact unicycle/nonholonomic arc stepping with closed-form trigonometric invariants.
- **High-Order Steppers**: Runge-Kutta and high-order geometric integrators.
- **Lyapunov Navigation**: Global feedback-stabilized navigation to target poses.
