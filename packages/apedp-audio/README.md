# APEDP-Audio

Autonomous Audio Spectrogram Field Transport, Continuous STFT Ridge Tracking, and 2nd-Order Jet Frequency Advection.

## Installation

```bash
pip install -e packages/apedp-audio
```

## Features

- **STFT Ridge Tracking**: Instantaneous frequency ridge extraction on non-stationary chirps.
- **2nd-Order Jet Advection**: High-order material derivative transport beating standard Euler integration on accelerating chirps.
