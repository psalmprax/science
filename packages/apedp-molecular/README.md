# APEDP-Molecular

Autonomous Molecular SE(3)-Equivariant Flow, Rigid Invariance, Reflection Symmetry, and Potential Energy Relaxation.

## Installation

```bash
pip install -e packages/apedp-molecular
```

## Features

- **SE(3) Equivariance**: Guaranteed spatial rotation, translation, and mirror reflection symmetry.
- **Molecular Relaxation**: Continuous energy gradient descent satisfying target bond lengths and center-of-mass conservation.
