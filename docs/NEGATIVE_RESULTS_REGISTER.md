# Negative results register

A system that publishes only its positives is uncalibrated. This file records what the
platform's own artefacts say it has **not** established, with the file that measures each
claim, so a reader can check the refusals rather than take rigour on trust.

Nothing here is a restatement from memory: each row names the record generated by a script,
and the tests that keep those records current are listed at the end.

## 1. Patent prior art — a thin index that refuses seven of fifteen claims

Source: `benchmarks/patent_prior_art/prior_art_run.json`,
`data/patents/REFUSED_CLAIMS.md`, `data/patents/corpus.jsonl`.

| measure | value |
|---|---|
| records | 29 |
| normalised claims | 15 |
| decisive claims (able to carry a verdict) | 8 |
| claims refused as operand-only | 7 |
| records with a stated relation | 7 |
| records stating no relation in any claim | 22 |
| formulas the automatic extractor parsed from claim text | 0 of 501 |
| declared decisive-claim floor | 50 |

Consequences, both enforced in code:

- Every verdict from this index states that it holds 8 decisive claims against a floor of
  50, and that absence here is absence from a **thin index**, not from the patent literature.
- Seven normalised claims cannot decide anything: they name operands and one operation
  (`Z_meas/Z_ref`, `I_lim*V_min`, `C_t_I/C_0_I`, `C_t_E/C_0_E`, `eta_C*i_ch`, `V_in/V_out`,
  `SoH_pred`), so any form built the same way is isomorphic to them. They are listed with
  their claim text in `data/patents/REFUSED_CLAIMS.md`.

The prior-art run's eight probes are all refusals or absences: two operand-only refusals, one
structural match (a different slope on the same form), and five `NOT_FOUND` verdicts.

## 3. Applied-science modules — reference tables, not predictions

Source: `benchmarks/applied_basis_report.json`, generated by
`scripts/audit_applied_basis.py`.

Every dictionary returned by `apedp/applied_*.py` carries an evidence label and, where
relevant, the list of things it did not model. The audit reports the count of unlabelled
returns and fails when it is non-zero. These modules describe literature-typical or
closed-form figures; they do not predict, discover, design or optimise anything, and the
distinction is now machine-checked rather than stated in prose.

## 5. Benchmark I (inverse square root) — every clean-room family is score-negative

Source: `docs/INVSQRT_NEW_DECOMPOSITION_SPEC.md` (this session's screens),
`docs/INVSQRT_SUB62_DESIGN.md` (measured levers), and the proposer artefacts under
`artifacts/quantum_compilation/`.

The question "design a better circuit without using the shipped 89-Q one as design knowledge"
has been answered by measurement, not argument. Each row names the family and the number that
refuses it.

| family | measured | refuses |
|---|---|---|
| piecewise-quadratic Horner (`invsqrt_direct_poly`, 12 precision points swept) | best **Q = 135 / T = 3,464** at (10, 23, 10) | ≥ 2.4× the champion's 157,601.08 |
| QROM piecewise-linear seed (`invsqrt_qrom_line`) | Q = 213–226, T = 5,886–6,872 | ≥ 3.6× the champion |
| Newton-Raphson reference, in-repo (`nr_reference_circuit`) | **Q = 260 / T = 7,735**, all registers simultaneously live; hand-recycled dependency graph floors at Q ≈ 130–170 | wider *and* 5× the Toffolis |
| digit-serial, per-digit full-prefix (`prototype_bitserial_sqrt`, 22 bits) | 34,997 Q / 101,914 T | — |
| digit-serial, one shared multi-output PDDD (`prototype_digit_shared_pddd`) | 1.4–1.5× **wider** at every k for ~1% of the Toffolis | wrong exchange at 26.2 te/qubit |
| digit emission screen (new, this session) | residual/tol 1.3e5 → 2.0e3 → 30 after 6/12/18 mantissa bits; tolerance needs all 22 | the last digit's table is `2^22` entries |
| phase truncation screen (new, this session) | truncating the 38-bit phase to 24 bits fails 3,129,842 of 3,133,452 points by up to **1,820×** tolerance | the accumulator cannot be narrowed |
| direct per-product phasing, no accumulator (new, this session — built, not priced) | 105 Toffolis / **119 rotations** against the champion outer's 280 / 20: **te 983 vs 420, 2.34× worse**; whole-circuit estimate 182,521 vs 157,601 | see below |
| phase-kickback table load, to drop the 21-bit accumulator (new, this session) | all 256 ANF masks of the champion's 54-bit table are nonzero: **6,676 rotations** against 44, ≈ +48,911 te | the qubit saving is unreachable |

**Why the last two lose, and why it is the same reason the champion is shaped as it is.** The
verifier prices a rotation at `0.56 log2(1/eps) + 5.3` with `eps = π·min_margin/2^64/n_rot`, so
the per-rotation cost **grows with the rotation count** whenever the phase margin is tight — and
it is tight by construction, since `min_margin ≤ tol(x)`. The accumulator is a rotation
compressor: it folds 105 `sign_i · R[j]` product terms into 21 bits, so 21 rotations replace
119. Break-even for the direct scheme needs `eps > 0.11`, a phase margin of 0.042 turns, which
is 700,000× the tolerance at `x = 1` and therefore unreachable. Any design that raises the
rotation count is worse at any accuracy, which is a measured property of the cost model rather
than an artefact of this arithmetic.

Two structural facts behind all of it, both measured this session: the verifier's tolerance is
**relative** (`2^-24 · β/√x`), so ~38 bits of *absolute* phase precision are required and any
held-accumulator design floors near 86 qubits; and the pinned `kickmix` binary has **no `mr`**
(Z-basis read), so carry-chain segmentation and classical branching — the only measured levers
left — cannot be built at all (`docs/MR_INSTRUCTION_SPEC.md` specifies `mr`;
`apedp_dyn/quantum_compilation/contracts.py` still pins the official binary without it).

What this register does **not** claim: that no circuit below 62 qubits exists. The public
62-Q circuit (`sha256 bce2948f…`, 100,569.53) is evidence that one does; it is not vendored in
this repository, and no family available here reaches it.

## 6. What still has no negative record

The system has no register yet for hypotheses it *accepted* and later failed to replicate;
those live in the experiment ledger rather than here. That is a gap, not a pass: an absence
of replication records is not evidence that accepted candidates held up.
