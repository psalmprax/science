# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/psalmprax/science/security/advisories/new)
if it is enabled for this repository. If private reporting is unavailable, contact
the repository owner through [GitHub](https://github.com/psalmprax) and ask for a
private disclosure channel. Do not open a public issue or include exploit details
in a public pull request.

Include the affected version or commit, impact, reproduction steps, and any
suggested mitigation. Avoid accessing, modifying, or exposing data that is not
yours while investigating.

## Acknowledgment and disclosure

We aim to acknowledge reports within seven calendar days; this is a best-effort
target, not a guaranteed service level. We will coordinate investigation,
remediation, and a public disclosure date with the reporter. Unless the parties
agree otherwise, we target disclosure after a fix is available or within
90 days of the report, whichever is earlier. Please allow reasonable time to
assess and correct a report before public disclosure.

## Supported versions

This project is early-stage and no tagged releases were recorded when this
policy was established. Security fixes are prioritized for the default branch
and, if published releases are available, the latest release of each affected
artifact. Older releases are not guaranteed security support; users should
upgrade to the latest supported release or current default branch.
